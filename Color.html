CSS Types

CSS are of 3 Types

  1. Inline CSS: Defined directly in the html
  2. Internal CSS: Defined in the head section of the html
  3. External CSS: Defined in a separate .css file and linked to the HTML document

This is a standalone paragraph.

# is used for id selector and . is used for class selector. The id selector is used to select a single element with a specific id attribute, while the class selector is used to select multiple elements with a specific class attribute.
